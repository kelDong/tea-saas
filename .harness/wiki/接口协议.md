# 接口协议（API 契约）

> API 设计约定与完整接口清单。**权威文档：`docs/茶饮SaaS-接口需求.md`（v1.0，约 130 接口）**；本页为其精炼投影，冲突时以 docs 为准。所有接口必须遵循，作为前后端与 AI 协作的契约。

## 1. URL 前缀与认证

| 前缀 | 使用者 | 认证 |
|---|---|---|
| `/api/admin/v1/**` | 平台管理员（R1） | Sa-Token |
| `/api/v1/**` | 总部/加盟商/店长/店员（R2–R8） | Sa-Token（Bearer token） |
| `/api/app/v1/**` | 顾客小程序 | 微信登录（openid 解析租户） |
| `/api/notify/**` | 微信支付回调 | 验签，无会话 |

## 2. HTTP 方法语义

| 方法 | 语义 | 示例 |
|---|---|---|
| GET | 查询（幂等） | `GET /api/v1/orders?storeId=&status=` |
| POST | 创建/动作 | `POST /api/v1/orders`、`POST /api/v1/orders/{id}/accept` |
| PUT | 全量更新 | `PUT /api/v1/products/{id}` |
| PATCH | 部分更新 | `PATCH /api/v1/listings/{id}/price` |
| DELETE | 逻辑删除 | `DELETE /api/v1/materials/{id}` |

## 3. 统一响应

```json
{ "code": 0, "message": "success", "data": { }, "traceId": "..." }
```

- `code=0` 成功；非 0 失败（见错误码）；分页 `data`：`{ "list": [], "total": 0, "page": 1, "size": 10 }`
- 字段约定：金额一律"分"（Integer）；枚举传 code；时间 `yyyy-MM-dd HH:mm:ss`；分页 `page`（从1）、`size`（默认10上限100）

## 4. 错误码（模块(2)+场景(2)+序号(2)）

| 编码 | 含义 | 编码 | 含义 |
|---|---|---|---|
| 000001 | 参数错误 | 030102 | 订单状态不允许该操作 |
| 000002 | 未登录/会话过期 | 040201 | 支付回调签名校验失败 |
| 000003 | 无权限 | 060102 | 采购单状态不允许该操作 |
| 030101 | 订单不存在 | 070101 | 库存不足 |
| 010001 | 品牌不存在/已停用 | 070102 | 库存操作并发冲突 |

模块：00 通用 / 01 系统 / 02 产品 / 03 订单 / 04 支付 / 05 会员 / 06 供应链 / 07 库存 / 08 加盟 / 09 营销 / 10 报表

## 5. 接口清单速览（按模块，完整见 docs/茶饮SaaS-接口需求.md）

### 系统与权限（F-SYS-01~04）
- 登录 `POST /api/v1/auth/login`（账号+验证码）｜ 验证码 `GET /api/v1/auth/captcha` ｜ 菜单+按钮权限 `GET /api/v1/auth/menus`
- 品牌 `GET/POST/PUT /api/admin/v1/tenants`（R1）｜ 套餐 `GET /api/admin/v1/packages`（R1）
- 用户 `GET/POST/PUT /api/v1/users` ｜ 角色 `GET/POST /api/v1/roles`（R2）
- 操作日志 `GET /api/v1/operation-logs`（R2 全量/本人）

### 产品研发 BOM（F-BOM-01~03）
- 原料 `GET/POST/PUT/PATCH /api/v1/materials`（R2/R3）
- 配方 `GET/POST/PUT /api/v1/formulas` + `/{id}/copy` + `/{id}/publish`（R2/R3）
- 毛利试算 `POST /api/v1/formulas/calc-profit` → `{costTotal, grossProfit, grossMargin}`

### 供应链（F-SUP-01~04）
- 供应商 `GET/POST/PUT /api/v1/suppliers`（R2/R4）
- 分级价格 `PUT /api/v1/tier-prices/batch`（R2/R4）
- 采购单（**R6 发起**，P1-1）：`POST /api/v1/purchase-orders` → `/confirm`(R4) → `/ship`(R4) → `/receive`(R6/R7) → `/cancel`；计价按加盟商等级取分级价格快照；入库联动库存+流水（F-SUP-04）

### 加盟商与门店（F-FRA-01~02）
- 加盟商 `GET/POST/PUT /api/v1/franchisees` + `POST /api/v1/franchisees/{id}/level`（等级评定）+ `POST /api/v1/franchisees/{id}/account`（R2/R5）
- 门店 `GET/POST/PUT /api/v1/stores` + `PATCH /api/v1/stores/{id}/business-status`（R2/R5/R7 本店）

### 商品与上架（F-PRD-01~03）
- 商品 `GET/POST/PUT /api/v1/products` + `/{id}/price` + `/{id}/off`（R2/R3）
- 上架 `POST /api/v1/listings` + `/{id}/price` + `/{id}/off`（R6）
- 可售列表 `GET /api/app/v1/stores/{id}/products?category=`（服务端按 BOM 库存过滤，F-PRD-03/F-INV-02）

### 库存（F-INV-01~03）
- 台账 `GET /api/v1/inventories?storeId=` ｜ 流水 `GET /api/v1/inventories/{storeId}/{materialId}/logs`
- 盘点修正 `POST /api/v1/inventories/adjust`（R6/R7）｜ 预警 `GET /api/v1/inventories/warnings`

### 订单（F-ORD-01~04）
- 下单 `POST /api/app/v1/orders`（二次校验库存；15 分钟未付自动取消回补，P1-5）｜ 预览 `POST /api/app/v1/orders/preview`
- 状态机 `POST /api/v1/orders/{id}/accept|make|finish`（R6/R7/R8）
- 门店收银（F-ORD-04/P0-1）：`POST /api/v1/pos/orders` + `/{id}/pay`（现金/微信码Native/储值三选一，order_source=2）
- 新订单推送 `WS /ws/orders`（WebSocket，P1-2）

### 支付（F-PAY-01~03）
- 微信 JSAPI `POST /api/app/v1/payments/wx-jsapi` ｜ Native 收款码 `POST /api/v1/payments/wx-native`
- 回调 `POST /api/notify/wx-pay/callback`（验签→幂等→落 pay_callback_task 定时重试，P1-3）
- 退款 `POST /api/v1/orders/{id}/refund`（**整单退，券不退还**，储值退储值账户/微信原路，P0-5）
- 对账 `POST /api/v1/reconcile/run` + `GET /api/v1/reconcile?date=`（R2）

### 会员（F-MEM-01~03）
- 微信登录建档 `POST /api/app/v1/auth/wx-login` ｜ 会员信息 `GET /api/app/v1/members/me`
- 积分明细 `GET /api/app/v1/members/me/points` ｜ 储值 `POST /api/app/v1/members/me/wallet/recharge`（**独立通道不与微信混合**，P0-4）

### 营销（F-MKT-01）
- 券模板 `GET/POST/PUT /api/v1/coupon-templates`（R2/R5）｜ 领券 `POST /api/app/v1/coupons/{templateId}/claim` ｜ 我的券 `GET /api/app/v1/coupons`

### 报表（F-RPT-01~03）
- 门店报表 `GET /api/v1/reports/store?storeId=&granularity=day|week|month`
- 看板 `GET /api/v1/reports/dashboard` ｜ 热销 `GET /api/v1/reports/hot-products` ｜ 排行 `GET /api/v1/reports/store-ranking`
- 原料消耗趋势 `GET /api/v1/reports/material-consumption`（**二期**）

### 顾客端（F-APP-01~03）
- 附近门店 `GET /api/app/v1/stores/nearby?lng=&lat=` ｜ 历史订单 `GET /api/app/v1/orders` ｜ 再来一单 `POST /api/app/v1/orders/{id}/reorder`

## 6. 优先级

- **MVP 必做**：约 60 个接口（总则 + 全部业务模块 C 端/B 端 + 小程序端）
- **二期**：原料消耗分析、购物车快照、套餐 CRUD 细化、会员等级自动化、拼团/秒杀

## 7. 安全与鉴权

- B 端：Sa-Token（账号+验证码），登录后返回菜单树+按钮权限码；C 端：微信登录
- 所有"按 id 操作"接口校验归属（tenant_id + store_id 匹配当前上下文）
- 全站 HTTPS；敏感字段脱敏；下单/支付/登录接口限流
