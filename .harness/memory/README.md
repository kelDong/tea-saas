# 会话记忆

本目录保存**每次 AI 会话**的过程记录，供后续会话快速恢复上下文。

## 与相邻目录的分工

| 目录 | 记什么 | 粒度 |
|---|---|---|
| `memory/`（本目录） | 每次会话：做了什么、决策、提交、遗留 | 一次会话一份 |
| `../changes/` | `docs/` 与 `.harness/` 的实质性变更 | 一次实质变更一份 |
| `../../HANDOFF.md` | 当前最新进度快照（滚动覆盖） | 始终只有一份 |

## 记录规则

- 文件命名：`YYYY-MM-DD-<主题>.md`，一天多场会话用 `-主题` 区分，不覆盖
- **会话开始**：先读本目录最近 2~3 份记录 + `HANDOFF.md` 恢复上下文
- **会话结束**（或到达重大节点）：按 `_TEMPLATE.md` 新增一份记录再收尾
- 记录要写"为什么"和"遗留什么"，纯代码 diff 交给 git，不要复制大段代码
- 涉及功能编号的写 F-XXX，涉及里程碑的写 M 编号，便于和 HANDOFF.md 对照
