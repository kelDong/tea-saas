# 抖音推广 — 产品功能介绍视频脚本（第一批 8 集）

> 版本 v1.0 | 2026-10-10
> 产品：茶饮 SaaS 连锁经营系统（管理后台 + 门店平板端 + 微信小程序）
> 用途：抖音企业号发布，B 端获客（茶饮/甜品连锁老板、加盟商、准开店创业者）
> 脚本中所有功能点均来自 PRD/接口需求文档已实现能力（截至 M18），无虚构演示

---

## 一、系列定位

- **账号人设**：懂茶饮生意的数字化工具号（后续可孵化老板 IP 口播号）
- **目标**：短视频获客 → 私信/评论区留资 → 销售跟进免费试用
- **考核指标**：私信线索数（CPL），不是播放量
- **每集时长**：45~60 秒，竖屏 9:16
- **统一 CTA**：「开店的老板，评论区扣【关键词】，或点头像私信【试用】」
- **统一话题**：#茶饮创业 #奶茶店经营 #收银系统 #连锁门店管理 #餐饮数字化

## 二、拍摄前准备（每集通用）

### 演示环境
- [ ] 本地起全套服务（backend + admin-web + mini-program 微信开发者工具），跑通 tools/smoke 后环境即为可用态
- [ ] 准备一个"演示品牌"：2 家门店（1 直营 1 加盟）、约 10 个商品（含图片、含多规格如去冰/半糖）、若干原料（其中 1~2 个故意压到预警线以下）
- [ ] 准备演示会员：有积分 + 储值余额 + 2 张券（1 满减全场 + 1 指定商品券）
- [ ] 平板端用浏览器打开 admin-web 门店角色（M17 已适配平板 CSS），开声音录"叮"提示音

### 录制口径（重要）
- **微信支付当前为沙箱 mock 通道**（真实商户资质待办）：视频演示收付款流程没问题（界面一致），但**口播不要说"已正式上线微信收款"**，统一说"支持微信支付/现金/储值三种收款方式"
- 视频里**不放套餐价格**（99/199/299），报价留给私信/私域
- 案例数据只用演示环境数据，不编"某品牌提升 X%"——避免广告法收益承诺风险
- 录屏分辨率：后台/平板横屏内容录完裁 9:16 竖屏，关键数字区域占屏 ≥1/3

## 四、通用制作规格

| 项 | 规格 |
|---|---|
| 画幅 | 9:16 竖屏；录屏源素材 1080p 起，后台页面裁切后关键区域占屏 ≥1/3 |
| 前 3 秒 | 必须有大字钩子（封面字同款），无 logo 无片头 |
| 字幕 | 全程硬字幕，关键词（自动扣减/实时推送/自动对平）用琥珀色高亮 |
| 口播 | 真人出声优先（信任感）；无人出镜期可用 AI 配音起步，S1/S3 建议真人 |
| BGM | 轻快节奏但音量压低，S3 的"叮"声必须比 BGM 响 |
| 封面 | 统一模板：暖茶色底 + 大字标题 + 集数角标（和产品 UI 同色系，形成品牌记忆） |
| 评论区 | 置顶自评：功能清单 + 引导私信话术；每条"扣字"评论 1 小时内回复 |

## 五、发布节奏与观测

| 周 | 动作 |

| 迭代 | 数据最差的 1 集拆解钩子重拍；数据最好的方向做续集（如库存篇 → 盘点实操篇） |

## 六、合规红线（再次强调）

1. 不出现"月入 X 万""稳赚""提升 X%"等收益承诺，演示数据即真实系统数据
2. 不做招商加盟话术（避免触发特许经营备案资质要求），始终以"管理工具/SaaS 系统"定位
3. 套餐价格不上视频，私信/私域报价
4. 微信支付口播统一为"支持微信支付收款"，不说"已上线官方收款"（资质到位后再改口）
5. 后续若用真实客户案例，需客户书面授权
